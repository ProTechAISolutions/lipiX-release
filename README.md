# Lipix — offline voice dictation for Linux

Downloads and bug reports for [Lipix](https://lipix.arjundhiman.site).

- **Install:** download the `.deb` from the [latest release](https://github.com/Arjun-Dhiman-Codeyogi/lipix-releases/releases/latest) or from the website
- **Updates:** arrive automatically through Ubuntu Software Updater after install
- **Found a bug?** [Open an issue](https://github.com/Arjun-Dhiman-Codeyogi/lipix-releases/issues/new) — or use the "Report a problem" button inside the app
