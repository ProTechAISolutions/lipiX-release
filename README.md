# Lipix — offline voice dictation

Downloads and bug reports for [Lipix](https://lipix.arjundhiman.site).

## Install

Download the installer for your OS from the [latest release](https://github.com/ProTechAISolutions/lipiX-release/releases/latest):

| OS | File |
|---|---|
| Windows | `Lipix-Setup-<version>.exe` |
| macOS (Apple Silicon) | `Lipix-<version>-arm64.dmg` |
| Linux (Ubuntu/Debian) | `lipix_<version>_all.deb` |
| Linux (any distro) | `Lipix-<version>.AppImage` |

## Updates

- **Windows:** the app updates itself automatically
- **Linux (.deb):** updates arrive through Ubuntu Software Updater after install

## Found a bug?

[Open an issue](https://github.com/ProTechAISolutions/lipiX-release/issues/new) — or use the "Report a problem" button inside the app.
